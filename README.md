# houmo

HOUMO.AI (后摩智能) is a Chinese fabless semiconductor company founded in 2020 that develops compute-in-memory (CIM) edge AI chips for running large language models and other AI workloads on endpoint devices. Its products include the MOMAGIC (H30) series processors, LIQING M.2 modules, and Limou (LM 5050 / LM 5070 / LM 30) AI acceleration cards, paired with the Houmo Avenue software toolchain (PyTorch / TensorFlow / ONNX, CUDA-style front end) for model quantization, compilation, and deployment. Target markets include edge inference, autonomous driving, embodied robotics, and intelligent mobile devices.

This is a hardware / AI-chip vendor with a developer toolchain, not a public web API provider. No REST/OpenAPI, OAuth, or hosted API surface was found during enrichment.
